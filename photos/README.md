# Photos

Build photos go in this folder. The main [README](../README.md) references
them by the filenames below — use these names and they'll appear there
automatically; add extras with any name you like.

| Filename | Stage |
|---|---|
| `box-interior-empty.jpg` | Case interior before any modification (bin-tray ribs still in place) |
| `ribs-removed.jpg` | Left/right ribs cut flush with the oscillating tool |
| `sub-plate-fitted.jpg` | HDPE sub-plate cut and dry-fit to the case floor |
| `radio-mounted.jpg` | ICOM IC-2730A bolted to the sub-plate on its standoffs |
| `bulkheads-installed.jpg` | SO-239, TRRS, PowerPole, and RJ11/12 bulkheads mounted |
| `fan-vent-installed.jpg` | Fan and filtered vent shrouds in place |
| `esp32-wiring.jpg` | ESP32 / buck converter shelf, wired |
| `final-assembly.jpg` | Completed box, lid closed |

None of these are required before pushing the repo — add what you have and
fill in the rest as the build progresses.
